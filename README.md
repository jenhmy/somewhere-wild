<h1>
  🌲 Somewhere Wild
</h1>

The project presents a collection of travel and nature photography through a clean, responsive interface designed to keep the focus on the images.

It allows users to explore different places, filter photographs by country or region, search for locations, open individual galleries, and view related information such as Google Maps and Wikiloc links.

## ✨ Main Features 

- Dynamic photography gallery 
- Filters by country and region 
- Search by place - Featured locations 
- Individual gallery for each place 
- Google Maps and Wikiloc links 
- Interactive map - Fullscreen image lightbox 
- Dark and light themes 
- Responsive navigation and filters

---
## 📱 Responsive Design

The website automatically adapts to different screen sizes: 

- **Desktop**: photographs are displayed in a multi-column gallery. 
- **Tablet**: the gallery is reorganized into two columns. 
- **Mobile**: photographs are displayed in a single column. 
- **Small screens**: navigation and filters become dropdown menus. 
- **Lightbox**: images automatically adjust to the available screen space.
